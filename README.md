## 🚀 About Me

I'm a **Principal Product Manager at Microsoft**, working on [Azure Cosmos DB](https://learn.microsoft.com/azure/cosmos-db/) — Microsoft's globally distributed NoSQL database. With **13+ years** in the software industry, I build developer tools, contribute to open-source projects, and speak at conferences worldwide to help developers grow and thrive in tech.
